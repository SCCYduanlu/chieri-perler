# 291-colour palette

The project contains a 291-entry palette transcribed from the user-provided workbook `Mard 291.xlsx`.

Each entry keeps its source code, series, Chinese name, English name and RGB value. Two distinct product codes are intentionally allowed to share the same RGB value; they remain separate inventory choices and are not deduplicated.

The original workbook is not included in this repository. The palette is a software reference for rendering and nearest-colour matching, not a guarantee that a monitor will match a physical bead under every lighting condition. Product codes, series names and trademarks belong to their respective owners. This project is not affiliated with or endorsed by a bead manufacturer.
